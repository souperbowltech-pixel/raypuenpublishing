# World image assets

Made with the built-in image generation tool on 2026-11-18. Each prompt used the
exact style line followed by its table prompt from the local image prompt file.
The named covers were inspected and supplied as character identity references.
The first felt Geezy was also supplied as the shared material and style reference.
No images were skipped. No substitute artwork was used.

Pillow, already available on this computer, resized the generated originals and
reduced PNG palette colours where needed. All final files were reopened and
decoded, measured, and checked for alpha. Sizes below are decimal bytes.
